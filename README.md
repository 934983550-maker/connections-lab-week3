 I want to create an interactive personality and survival simulator inspired by personality classification systems such as MBTI and the atmosphere of 1980s supernatural mystery stories. Instead of simply asking users what kind of person they are, the website will place them in different fictional situations and ask them how they would react. Their choices will gradually build a profile based on traits such as courage, curiosity, loyalty, caution, and risk-taking. At the end, the user will receive a fictional character archetype and a visual “survival profile” showing how they might behave in a supernatural world. The character types and scenarios will be part of an original dataset, allowing the project to explore how personality can be represented through choices and behavior rather than a fixed personality label.
